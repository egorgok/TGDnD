# D&D Telegram RPG Bot

Телеграм-бот для ролевых игр в стиле D&D 5e.

## 🎮 Возможности

- **Создание персонажей** с расами и классами из D&D 5e
- **Система действий** с проверками (d20)
- **Инвентарь и экипировка** с добавлением/удалением предметов
- **Групповые приключения** с общим миром и изолированными персонажами
- **ИИ как гейм-мастер** для валидации действий и генерации событий
- **Генерация изображений** локаций и боевых сцен
- **Система боя** с инициативой и броском атаки
- **Профили персонажей** с характеристиками, способностями, заклинаниями

## 🛠️ Установка

### Требования
- Python 3.10+
- PostgreSQL 12+
- Redis 6+

### Шаги установки

1. **Клонируйте репозиторий**
```bash
cd /home/egorgok/VSCode/TGDnD
```

2. **Создайте виртуальное окружение**
```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

3. **Установите зависимости**
```bash
pip install -r requirements.txt
```

4. **Создайте `.env` файл**
```bash
cp .env.example .env
# Отредактируйте .env с вашими токенами и настройками
```

5. **Инициализируйте БД**
```bash
psql -U postgres -f database/schema.sql
```

6. **Запустите бота**
```bash
python src/bot.py
```

## 🎯 Основные команды

- `/start` - Главное меню
- `/profile` - Показать профиль персонажа
- `/create_character` - Создать нового персонажа
- `/action [описание]` - Выполнить действие
- `/create_group` - Создать группу/кампанию

## 📊 Структура БД

- **users** - Пользователи телеграма
- **groups** - Группы/кампании
- **characters** - Персонажи игроков
- **character_attributes** - Характеристики (STR, DEX, CON, INT, WIS, CHA)
- **character_abilities** - Способности и баффы
- **items** - Каталог предметов
- **inventory** - Инвентарь персонажей
- **locations** - Локации в мире
- **game_sessions** - Текущие игровые сессии
- **action_history** - История действий
- **d_d_rules** - Кэш правил D&D

## 📚 Open5e SRD

Импортировать или обновить кэш правил, классов, заклинаний, существ, оружия и брони:

```bash
python -m src.services.open5e_importer
```

При первом запуске бот также проверяет кэш и загружает недостающие данные автоматически.
Для этого серверу нужен доступ к `api.open5e.com`.

Импорт сохраняет записи SRD 5.1 в `d_d_rules`, а оружие и снаряжение — в `items`.
Новые персонажи получают стартовые особенности, снаряжение и доступные на 1-м уровне
заклинания своего класса. Для ранее созданного персонажа эти данные применяются при
первом открытии профиля после импорта.
